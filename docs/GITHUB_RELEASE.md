# Versions and downloads

Download installation ZIPs from [Releases](https://github.com/oldip/PeakAdminToolkit/releases).
Each ZIP contains PeakAdminToolkit.dll, installation instructions and license notices.
Source is available from the corresponding tag.

Version tags match the toolkit version: `v0.8.1`, `v0.8.2`, etc.
Patch versions identify fixes and maintenance updates. Published tags stay fixed;
subsequent changes use a new version. Release notes describe the changes.
