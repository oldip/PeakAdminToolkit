# Retained project data

These project-owned lookup tables are retained byte for byte for provenance.
PEAK Admin Toolkit does not load or embed them. Pinyin/initial search is
removed; Chinese script normalization uses Windows NLS and PEAK's translations.

The original SHA-256 values are recorded in `SHA256SUMS.txt`.

The descriptions/ subdirectory contains separately attributed third-party text;
it is not part of the project-owned TSV tables above.
